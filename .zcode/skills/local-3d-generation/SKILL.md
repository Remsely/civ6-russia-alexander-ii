# Локальная генерация 3D (Hunyuan3D 2.1)

> **Лицензия** (`C:\AI\HY3D2\Hunyuan3D2_WinPortable\Hunyuan3D-2.1\LICENSE`): бесплатно, коммерческое использование разрешено (до 1 млн MAU), на Output Tencent прав не заявляет (п. 5d). Но п. 5c запрещает использовать, распространять и показывать Output «outside the Territory», а Territory — весь мир, кроме ЕС, Великобритании и Южной Кореи. Workshop и GitHub Releases раздают мод и туда. 2026-10-15 пользователь принял этот риск: Hunyuan остаётся основным генератором, в том числе для публикуемого мода. Заново этот вопрос не поднимать. TRELLIS.2 (MIT) на этой машине не замена: нужно ≥24 ГБ видеопамяти и Linux.

Генерация живёт вне репозитория: `C:\AI\HY3D2` (портативная сборка YanWenKun v4-cu129, ~29 ГБ). Машина: RTX 4070 Ti 12 ГБ, 64 ГБ RAM, файл подкачки 32–64 ГБ (commit limit ~96 ГБ). Скрипт `tools\hy3d_gen.py` повторяет gradio-приложение в режиме малой видеопамяти (mmgp profile 5).

## Для чего годится, а для чего нет (проверено)
- **Голова и бюст — да.** Голова по кропу портрета выходит узнаваемой; бюст по `alexander_ii_short.png` даёт эполеты, ордена, аксельбанты формой.
- **Тело для анимации — нет.** Тело в полный рост выходит «кашей» с бесформенным лицом, а сгенерированную (и вылепленную SDF) сетку не заригать: её нельзя нормально анимировать. Поэтому тело лидера — MPFB со скелетом, а генерация даёт голову и, возможно, отдельные жёсткие детали.
- Текстура генерации бледнее картинки — лечится проекцией референса (ниже).

## 1. Вход
Картинка RGBA с прозрачным фоном, объект по центру квадрата. **Альфу бинаризовать** (порог 128): с мягкой альфой голова генерируется пустым кубом.
```python
from PIL import Image
im = Image.open(SRC).convert('RGBA')
a = im.getchannel('A').point(lambda v: 255 if v >= 128 else 0); im.putalpha(a)
im = im.crop(a.getbbox()); w, h = im.size; s = max(w, h)
c = Image.new('RGBA', (s, s), (0, 0, 0, 0)); c.paste(im, ((s - w) // 2, (s - h) // 2)); c.save(OUT)
```
Готовить проектным `.venv\Scripts\python.exe` (Pillow есть). Входы кладутся в `C:\AI\HY3D2\in\` (`head_hard.png`, `bust_hard.png`, `full_hard.png`) — новый вход под новым именем, старые не перезаписывать.
Голову брать кропом из `art/source/alexander_ii_short.png` (лицо крупнее, чем в полный рост): макушка с волосами, бакенбарды, шея и верх воротника, поле ~8% по краям — как в удачном `in\head_hard.png` (1024×1024, превью `in\head_hard_preview.jpg`). Координаты кропа подобрать, посмотреть превью на сером фоне самому и показать пользователю до запуска.

## 2. Запуск — один seed на процесс, отдельно от Claude Code
Процесс съедает ~52 ГБ commit. Однажды второй seed в том же процессе исчерпал память, и Claude Code упал с мусором в терминале — дважды. Поэтому:
- **один seed на запуск**; несколько вариантов — несколько запусков подряд, не параллельно;
- запускать **через WMI**, чтобы процесс не был дочерним для консоли Claude Code (не `run_in_background`, не `Start-Process` из нашей оболочки, без `chcp`):
```powershell
$cmd = 'cmd.exe /c C:\AI\HY3D2\run_gen.bat C:\AI\HY3D2\in\head_v2_hard.png C:\AI\HY3D2\out\head_v2 --octree 512 --seeds 7 > C:\AI\HY3D2\out\head_v2_seed7.log 2>&1'
$r = Invoke-CimMethod -ClassName Win32_Process -MethodName Create -Arguments @{ CommandLine = $cmd; CurrentDirectory = 'C:\AI\HY3D2' }
"rc=$($r.ReturnValue) pid=$($r.ProcessId)"
```
- **Каждая новая серия — в новую папку** (`out\head_v2`, `out\head_v3`…): та же папка перезапишет `input_rgba.png` и `seed<N>` с уже выбранными результатами (`out\head\seed7`).
- Несколько вариантов: seed'ы 7, 42, 1234 (между ними была заметная разница), следующий запускать только после `ALL DONE` и исчезновения процесса python.

Параметры `hy3d_gen.py`: `--seeds N`, `--octree 512` (**по умолчанию в скрипте 256** — грубее; всегда указывать 512 явно), `--steps 50`, `--guidance 5.0`, `--faces 40000` (после упрощения), `--no-tex` (только форма). `run_gen.bat` уже ставит `PYTHONIOENCODING=utf-8` — без него падало на китайском выводе (`UnicodeEncodeError: 'charmap'`).
- Память во время прогона можно писать `tools\memlog.ps1 -Out C:\AI\HY3D2\memlog_<имя>.csv -Seconds 900` (тоже через WMI); сам завершится через `-Seconds`, досрочно: `Get-CimInstance Win32_Process -Filter "Name='powershell.exe'" | ? CommandLine -match 'memlog' | % { Stop-Process -Id $_.ProcessId -Force }`. Колонки: `commit_used_gb` против `commit_limit_gb` (числа с запятой — русская локаль).
- Перед запуском сказать пользователю, что компьютер ~5 минут будет загружен (GPU, ~50 ГБ памяти), и что игру и тяжёлый Blender лучше закрыть. Пользователь об этом беспокоится — объяснять заранее, а не после.

## 3. Ждать и проверять
Время на seed (octree 512): форма ~3,5–4 мин (`SHAPE DONE`), текстура ~1 мин (`TEXTURE DONE`), в конце `ALL DONE`. Проверять лог раз в несколько минут (`grep -E "DONE|Error" <log>`), а не частым опросом.
- `ModuleNotFoundError: No module named 'triton'` с трассировкой — **безвредно** (xformers без Triton), не ошибка.
- `CLEANUP SKIPPED` — пропущена чистка сетки, не страшно.
- Процесс жив? `Get-CimInstance Win32_Process -Filter "Name='python.exe'"` и смотреть `CommandLine` с `hy3d` (`ParentProcessId` — кто запустил).

**Мусор в терминале / Claude Code падает во время генерации.** Причина была в памяти: генерация запущена из нашей консоли (дочерний процесс) или с несколькими seed — commit кончается, и страдает терминал Claude Code. Компьютеру это не вредит. Что делать: найти процесс (см. выше); если он запущен не через WMI или с несколькими `--seeds` — `Stop-Process -Id <pid> -Force` и перезапустить правильно по одному seed; если запущен правильно — не трогать, дождаться `ALL DONE` в логе. Если терминал уже сломан — пользователь перезапускает Claude Code (при сильной нехватке памяти — компьютер); результаты в `out\` сохраняются по seed.

Выход `out\<имя>\seed<N>\`: `white_mesh_full.glb` (сырая форма, ~2 млн треугольников), `white_mesh.obj` (40k), `textured_mesh.obj/.glb` + `textured_mesh.jpg` (albedo), `_metallic.jpg`, `_roughness.jpg`, `stats.json`; в `out\<имя>\input_rgba.png` — что реально ушло в сеть.

## 4. Показать результат
Рендер превью в фоне (сетка из obj/glb, ортокамера, ракурсы 0°/35°/90°/180°, файлы `<out_prefix>_a0.png` … `_a180.png`):
```
"C:\Program Files\Blender Foundation\Blender 4.5\blender.exe" -b --python C:\AI\HY3D2\tools\preview_obj.py -- <mesh.obj|glb> C:\AI\HY3D2\render\<имя>_s<seed>
```
Рендеры класть в `C:\AI\HY3D2\render\`. Blender запускать только после окончания генерации (память).
`preview.py` — то же для glb со статистикой (полигоны, материалы, bbox). Посмотреть рендеры самому, потом показать пользователю и сравнить seed'ы. В живом Blender — через MCP (пользователь должен нажать Start MCP Server в N-панели MCP for Blender).

## 5. Бледная текстура → проекция референса
`C:\AI\HY3D2\tools\project_ref.py` (запускать внутри Blender через MCP): фронтальная проекция картинки на сетку и запекание в собственную UV-развёртку albedo (4K). Референс — кроп по бинарной альфе (`in\bust_proj.png`), он должен совпадать с bbox сетки по XZ; фронт сетки — −Y (`FRONT_SIGN=-1`). Бока и спина берут цвет генерации, смешивание по нормали.
