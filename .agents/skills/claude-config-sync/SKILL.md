# Синхронизация скиллов проекта

Источник истины — `.agents/skills/` Codex. `.claude/skills/` и `.zcode/skills/` — зеркала: меняй исходный скилл, затем синхронизируй оба зеркала. Не меняй только зеркальную копию, иначе следующая синхронизация затрёт её.

```powershell
.venv\Scripts\python.exe .agents\skills\claude-config-sync\scripts\sync_claude_configs.py --check
.venv\Scripts\python.exe .agents\skills\claude-config-sync\scripts\sync_claude_configs.py
```

`--check` только показывает изменения и возвращает 1 при расхождениях. Синхронизация копирует все файлы каждого скилла, включая ссылки и скрипты; дополнительные файлы и скиллы в зеркалах не удаляет, а перечисляет. Если у общего скилла есть лишние файлы, проверка остаётся неуспешной до ручного решения. Запускай с синхронизацией после изменения `.agents/skills/` и проверяй результат.

Команда не перезаписывает `AGENTS.md`, `CLAUDE.md` или MCP-конфиги. Только при отдельной задаче на MCP можно добавить `--mcp`: это дополнительно синхронизирует `.mcp.json` → `.zcode/config.json` по схеме Z Code; перед записью проверь локальные изменения. Файл `.codex/config.toml` не затрагивается. `AGENTS.md` и `CLAUDE.md` — самостоятельные инструкции своих агентов, не зеркала.
