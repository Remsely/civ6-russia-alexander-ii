# Тексты лидера

Любая правка сразу в `Text/en_US.xml` и `Text/ru_RU.xml`; после неё `tools\validate.py`.

## Обязательный набор (его проверяет `check_required_leader_text`)
- `LOC_LEADER_<L>_NAME`: в ru шесть падежей через `|` плюс `<Gender>` и `<Plurality>`. То же для имён юнитов, зданий, районов, улучшений, цивилизаций.
- `LOC_LOADING_INFO_<LeaderType>` - абзац на экране загрузки; игра находит его сама по типу лидера.
- Цивилопедия: `LOC_PEDIA_LEADERS_PAGE_<LeaderType>_` + `TITLE`, `SUBTITLE`, `CHAPTER_CAPSULE_BODY`, `CHAPTER_DETAILED_BODY`, `CHAPTER_HISTORY_PARA_1..N`; `QUOTE` по желанию (см. ниже). Без них страница лидера состоит только из способностей.
- Способность и повестка: `LOC_TRAIT_LEADER_*_NAME/DESCRIPTION`, `LOC_AGENDA_*_NAME/DESCRIPTION`, тексты модификаторов повестки (`LOC_DIPLO_MODIFIER_*`).
- Дипломатия: набор тегов должен покрывать **все ванильные ключи реплик** лидера-образца (у Петра их 33); сверяй по базе, не по памяти.
- Города: `LOC_CITY_NAME_*` и `CityNames` с `LeaderType` (привязка списка к лидеру в игре не проверена).
- Описание и тизер мода: `LOC_<MOD>_MOD_DESCRIPTION/TEASER`. Имя в `.modinfo` можно красить `[COLOR_...]...[ENDCOLOR]`, но только цветами из `Civ6_ColorAtlas.xml` (`COLOR_FLOAT_CULTURE`, `COLOR_FLOAT_GOLD`, `COLOR_LIGHTBLUE`...). Цвета палитры игроков (`COLOR_STANDARD_ORANGE_MD`) в тексте дают невидимые буквы; валидатор это ловит. `COLOR_FLOAT_GOLD` занят JFD; голубой `COLOR_LIGHTBLUE` сливается с фоном меню, красный `COLOR_RED` - с сообщениями об ошибках; у нас пурпурный `COLOR_FLOAT_CULTURE`. Цвет проверяет только глаз в игре.

## Правила
- Без буквы «ё» (как в официальном тексте); префикс `REMSELY` у каждого тега (проверяет валидатор).
- Плейсхолдеры (`[ICON_...]`, `[NEWLINE]`, `{...}`, `%1`) в en и ru совпадают, регистр иконок сохраняется.
- Термины - `docs/terms.md` (источник - `DebugLocalization.sqlite`). Эпоху в документации называй «Античность», не «Классическая».
- **Цитаты** только реально сказанные, со сверкой по печатным источникам. Непроверенное не подключай: страница работает без цитаты, подключается через `LeaderQuotes`.
- Исторические факты (даты, суммы, названия) бери из дизайн-документа и помечай для вычитки.
- Консоль ломает кириллицу: русский текст читай и ищи инструментами Read/Grep, а не печатью через Bash.

## Почему так
Игра не сообщает об отсутствующем тексте: страница или экран просто выглядят пустыми (так у нас пропали описание в Цивилопедии и абзац на загрузке). Поэтому набор сверяют со списком выше и с ванильным лидером-образцом, а новые обязательные ключи добавляют в `REQUIRED_LEADER_TAGS` валидатора.
