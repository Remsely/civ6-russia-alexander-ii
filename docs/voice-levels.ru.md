Выбраны первая встреча четырёх лидеров базовой игры и четырёх Gathering Storm. События сверены по AST SDK. Для составных событий измеряется только VO, без фоли.

Метод: локальные WEM → PCM через vgmstream, интегральная громкость EBU R128 через ffmpeg `ebur128=peak=true`; сумма статических Volume на sound и всех actor-mixer до общей Speech Bus. Числа в последнем столбце — расчёт до общей шины, а не запись выхода игры. Общие настройки пользователя, динамический микс, эффекты/RTPC и восприятие тембра этим расчётом полностью не измеряются. Повторение: Python с `numpy`, `lxml`, `imageio-ffmpeg`, локальный pinned `bnktool.py` из инструкции интеграции и `art/build/voice/vgmstream/bin/vgmstream-cli.exe`; затем `python tools/analyze_voice_levels.py`. Отчёт с цепочками — игнорируемый `art/build/voice/integration/levels/report.json`. Оригинальные WAV/WEM других лидеров в репозиторий и мод не включаются.
