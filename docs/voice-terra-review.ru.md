# Проверка изменений Terra и уроков озвучки

2 ноября 2026. Проверены текущий diff, банк, манифесты, WAV, игровые XML, Lua, ванильные DiplomacyActionView.lua / DiplomacyStatementSupport.lua / LoadScreen.lua и доступный Lua.log. Анализ истории опирается на сообщения пользователя в этом чате и сохранённые планы/манифесты; отсутствующие ответы ассистента не восстанавливались как факты.

Последующее исправление: второй текст поражения подключён после этого аудита; схема и границы проверки — `voice-integration.ru.md`. Ниже описан исходный результат проверки Terra.

## Выводы по реализации

1. Банк действительно содержит 31 медиа: шесть прежних сцен, 24 дополнительные дипломатические пробы, одно русское вступление. Это 30 из 31 дипломатического текста плюс загрузка. Второй текст поражения не маршрутизирован отдельно: общий DEFEAT продолжает произносить AI-вариант. Полным покрытием это называть нельзя.
2. У новых реплик не учитывалось неопределённое настроение так, как его разрешает DiplomacyActionView. Копия SQL заменена штатным DiplomacySupport_ExtractStatement, добавлен GetPlayerMood при UNDEFINED. Первоначальное подозрение о неверной трактовке Initiator опровергнуто исходником: это ID инициатора; оснований менять его семантику нет.
3. Верификатор Terra проверял наличие и связи медиа, но не соответствие встроенного звука выбранным WAV. Теперь проверяются SHA исходников, формат и точное PCM16 после преобразования, тексты 24 проб и gain загрузки. Успех подтверждает структуру и содержимое, а не исполнение Lua в игре.
4. Статусы в manifest, каталоге и скилле отставали от фактической пробной интеграции. Обновлены. Каталог берёт файлы шести сцен и пробного manifest, а не просто последнюю папку кандидатов; английское вступление исключено из основного списка по просьбе пользователя.
5. Громкость загрузки рассчитана по пяти загрузочным рассказчикам, а не по дипломатическим приветствиям. Уровень около −17.6 LUFS до общей шины — оценка по PCM и статическим Volume; финальный игровой микс не записывался. Ссылка на Петра здесь относится к рассказчику загрузки, не к уже выровненной дипломатии.

## Что ещё не подтверждено

Новые обработчики LoadScreenContentReady и DiplomacyStatement не имеют свежего игрового подтверждения. Доступный Lua.log содержит старый маркер «Alexander statement to», которого уже нет в текущем файле. По нему нельзя судить о новой сборке. Необходимо проверить, загружаются ли InGame UI и банк до LoadScreenContentReady; не обрывает ли ShowLeaderScreen запущенную новым обработчиком реплику. Это риски порядка событий, не доказанные игровые ошибки. При испытании нужны маркеры «loading narration started» и «trial statement <slot>» и отсутствие Lua errors.

Ручная проверка после перезапуска игры: загрузка за Александра (начало, полный текст, громкость, прекращение при закрытии), новая встреча (один раз, без долгого ожидания), делегация/осуждение/сделка, Escape/RMB и смена лидера. Для шести сцен предыдущая проверка пользователя сохраняет историческую ценность, но не подтверждает расширение. Игру агент не запускает.

## Полезные изменения Harness

- Последовательность предпочтений загрузки: 64 → 96 → 128 шагов; итог — review-round11, seed 117, CFG 2, нормализация 0.85, без фильтра, atempo 0.88. Для первой встречи предпочтены 32 шага. Больше шагов не гарантирует результата для любой реплики.
- Пользователь отклонил ручную вставку паузы; новая генерация создала естественную паузу. Не лечить фразировку механической тишиной по умолчанию.
- Замедление может усилить произношение по слогам. Различать скорость артикуляции, паузы и общую длительность; хранить исходник для сравнения.
- При приглушённости сравнивать фильтр и отсутствие фильтра при одинаковой громкости. Для выбранного вступления предпочтён вариант без фильтра; причина любого нового дефекта требует отдельного сравнения.
- Торжественность не равна мягкой доброжелательности или драматическому нажиму. Император и рассказчик должны сохранять ясность, достоинство и размеренность.
- Словарь ошибок полезен: другОм / дрУгом, дАрами / дарАми, землИ / зЕмли, сУду / судУ; неудачные подсказки и согласованные замены подарками, границы, правосудию сохранены. Смысловой акцент «ценит» — отдельная задача, не словарное ударение; вариант дружбы временный.
- Разделять одобрение качества, включение в банк, установку и пользовательскую проверку; ранние статусы уступают актуальному manifest. Разрешённую установку завершать без нового запроса разрешения, проверяя реально скопированные файлы.

Обновлены civ6-leader-voice и civ6-mod-verify; зеркала Claude Code/Z Code синхронизируются штатным скриптом. Общие CLI-правила AGENTS.md и CLAUDE.md уже совпадают по смыслу; MCP и глобальные настройки не менялись. Наличие зеркал не доказывает, что Z Code прочёл их в конкретном сеансе.

## Выполненные проверки

- `tools/validate.py`: OK; `tools/verify_voice.py`: OK, проверены все 31 PCM и исходники.
- Контрольные повреждения без записи на диск: изменение байта встроенного PCM и изменение байтов исходного WAV обнаружены верификатором.
- `tools/test_skill_sync.py` запущен напрямую: OK. Это самостоятельный regression-скрипт, не pytest-тест: запуск через pytest подставляет свой argv вместо пути скрипта и даёт ложную ошибку.
- Синхронизация скиллов и последующий `--check`: зеркала совпадают. Frontmatter двух изменённых скиллов проверен отдельно; bundled quick_validate не запустился из-за отсутствующего PyYAML в проектном Python, новые зависимости ради этого не устанавливались.
- Исправленный Lua установлен штатным `tools/install.py`. SHA-256 всех 51 установленного файла совпадает с исходниками. Банк и BLP при этом не пересобирались: изменена логика UI, прежние PCM и длительности сцен сохранены.
- Выполнение нового Lua и порядок игровых событий требуют ручной проверки в игре; агент игру не запускал. Коммит и push в рамках этого поручения не выполнялись.
