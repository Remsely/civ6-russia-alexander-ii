# v2.0.0-alpha — release notes / описание выпуска

## English

- Rework the Great Reforms: Industrial Era Builder charges, a one-time Governor title and growth for cities with a Governor. Remove the old Pasture, unit-upgrade and Farm adjacency bonuses.
- Add railway Production from connected own cities and Gold from connected foreign cities; each bonus is capped separately by local Population. No Capital connection is required. Gathering Storm is required.
- Integrate Russian recordings for all 31 diplomacy texts on Windows, with separate selection for both defeat texts, and loading narration in Russian and provisional English.
- Restore the native era introduction before Alexander's loading narration, using the selected audio language and suppressing Peter's leader segment.
- Expand and revise RU/EN loading and diplomacy text; preserve selected takes, generation settings and listening feedback.
- Update audio validation, listening catalog, documentation and agent skills.

Known issue — delayed intro after restarting from the pause menu. After "Restart" the era narration starts a few seconds after the loading screen appears (Peter's voice is gone; Alexander's narration follows the era, and the "Begin" button skips the whole intro). Cause: a pause-menu restart rebuilds the loading screen from the game's own files while mods are not mounted yet, so the mod's code - the only thing that can start the narration without Peter's leader segment - does not exist until the engine loads the mod's interface near the end of the load. Making the game itself play the intro from the first second would also play Peter's voice (the game's data can only do "era + Russia's leader"), and nothing can mute him before the mod's code exists. No fix is known; this is an engine limitation. Details and history: docs/voice-integration.ru.md.

Development status: extended voice routes, loading narration, both defeat variants and gameplay changes still require final in-game checks. Some takes need polishing. Alexander always speaks Russian; loading narration now has Russian and provisional English recordings, selected by audio language. The English take at 90% tempo was selected by listening; playback in game still needs confirmation. Prepared for an alpha release; not yet published.

## Русский

- Переработаны «Великие реформы»: с Промышленной эры — заряды строителей, однократный титул губернатора и рост городов с губернатором. Убраны прежние бонусы пастбищ и улучшения юнитов, а также бонус смежности ферм.
- Добавлены производство за связанные рельсами свои города и золото за связанные чужие города; каждый бонус ограничен населением получателя, связь со столицей не требуется. Нужен Gathering Storm.
- Подключены русские записи всех 31 дипломатических текстов на Windows, отдельный выбор двух текстов поражения и вступление загрузки на русском и пробном английском.
- Загрузочный экран озвучен полностью: перед вступлением Александра играет ванильная начитка эпохи на выбранном языке озвучки (сегмент Петра отключается); корнем прежней тишины был флаг LoadingInfo.PlayDawnOfManAudio=0 с доозвучечных времён.
- Расширены и вычитаны русские и английские тексты загрузки и дипломатии; сохранены дубли, параметры генерации и отзывы.
- Обновлены проверки аудио, каталог прослушивания, документация и скиллы агентов.

Известное ограничение — задержка вступления после рестарта из меню паузы. После «Начать сначала» начитка об эпохе начинается на несколько секунд позже появления экрана загрузки (речи Петра при этом нет; вступление Александра звучит после эпохи, кнопка «Начать игру» пропускает вступление целиком). Причина: рестарт из паузы строит экран загрузки из ванильных файлов игры, пока моды ещё не подключены — код мода, единственный способный запустить начитку без сегмента Петра, в этот момент не существует и появляется лишь к концу загрузки, когда движок догружает интерфейс мода. Заставить саму игру проигрывать вступление с первой секунды нельзя без того, чтобы вместе с эпохой зазвучал Пётр (данные игры умеют только «эпоха + лидер России»), а заглушить его до появления кода мода некому. Способ исправления неизвестен — это ограничение движка. Подробности и история: docs/voice-integration.ru.md.

Состояние разработки: новые аудиопривязки, загрузка, обе ветки поражения и механики требуют итоговой проверки в игре. Часть дублей дорабатывается. Александр всегда говорит по-русски; рассказчик загрузки имеет русскую и пробную английскую записи, выбираемые по языку озвучки. Английский дубль с темпом90% выбран по прослушиванию; воспроизведение в игре ожидает проверки. Подготовлено для альфа-выпуска; релиз пока не опубликован.
