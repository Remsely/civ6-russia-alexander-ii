# v2.0.0-alpha — release notes / описание выпуска

## English

- Rework the Great Reforms: Industrial Era Builder charges and Farm Food adjacency, a one-time Governor title and growth for cities with a Governor. Remove the old Pasture and unit-upgrade bonuses.
- Add railway Production from connected own cities, capped by local Population, and Gold from connected foreign cities; no Capital connection required. Gathering Storm is required.
- Integrate Russian recordings for all 31 diplomacy texts on Windows, with separate selection for both defeat texts, and full Russian loading narration.
- Expand and revise RU/EN loading and diplomacy text; preserve selected takes, generation settings and listening feedback.
- Update audio validation, listening catalog, documentation and agent skills.

Development status: extended voice routes, loading narration, both defeat variants and gameplay changes still require final in-game checks. Some takes need polishing. Alexander always speaks Russian; only loading narration is intended to have an English recording, which is not yet selected or integrated. Prepared for an alpha release; not yet published.

## Русский

- Переработаны «Великие реформы»: с Промышленной эры — заряды строителей, однократный титул губернатора и рост городов с губернатором. Убраны прежние бонусы пастбищ и улучшения юнитов, а также бонус смежности ферм.
- Добавлены производство за связанные рельсами свои города и золото за связанные чужие города; каждый бонус ограничен населением получателя, связь со столицей не требуется. Нужен Gathering Storm.
- Подключены русские записи всех 31 дипломатических текстов на Windows, отдельный выбор двух текстов поражения и полное русское вступление загрузки.
- Загрузочный экран озвучен полностью: перед вступлением Александра играет ванильная начитка эпохи на выбранном языке озвучки (сегмент Петра отключается); корнем прежней тишины был флаг LoadingInfo.PlayDawnOfManAudio=0 с доозвучечных времён.
- Расширены и вычитаны русские и английские тексты загрузки и дипломатии; сохранены дубли, параметры генерации и отзывы.
- Обновлены проверки аудио, каталог прослушивания, документация и скиллы агентов.

Состояние разработки: новые аудиопривязки, загрузка, обе ветки поражения и механики требуют итоговой проверки в игре. Часть дублей дорабатывается. Александр всегда говорит по-русски; английская запись предусмотрена только для рассказчика загрузки и ещё не выбрана/не подключена. Подготовлено для альфа-выпуска; релиз пока не опубликован.
