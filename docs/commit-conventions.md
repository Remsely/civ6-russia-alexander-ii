# Коммиты проекта

Каждый коммит описывает одну связанную цель и только действительно включённые изменения. Заголовок — `тип(область): что изменено`: кратко, с глаголом, на русском или английском. Область необязательна; полезные типы — `feat`, `fix`, `refactor`, `docs`, `test`, `build`, `chore`. Исторические коммиты не переписываются.

```text
fix(animation): исправить рывки висящих деталей

Исправлены веса при экспорте; поза покоя сохранена.
Проверено: audit, сравнение вершин и импорт FBX.
В игре не проверено.

Co-authored-by: Codex <codex@openai.com>
```

Тело не обязательно для простой правки. Для сложной работы укажи причину решения, проверку и важные ограничения, особенно если поведение в игре не подтверждено. Не перечисляй в заголовке весь diff и не заявляй проверку, которая не проводилась.

Автор и коммиттер — штатная Git-идентичность пользователя; Codex не меняет её. Если Codex существенно участвовал в изменениях коммита, добавь отдельной строкой в конце `Co-authored-by: Codex <codex@openai.com>`. Это идентичность, используемая в публичном проекте OpenAI; автоматическое сопоставление строки с GitHub-аккаунтом зависит от GitHub. Указывай другого соавтора только при его фактическом участии; пользовательские правки не присваивай Codex. Git сам по себе не подписывает коммит этим трейлером.
