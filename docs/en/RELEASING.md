# Release Process

Russian version: [`../ru/RELEASING.md`](../ru/RELEASING.md). Pre-release testing: [`TESTING.md`](TESTING.md).

The release version (e.g. `1.0.0-alpha`) lives in the `VERSION` file and goes into the archive name and the tag. The `version` attribute in `.modinfo` stays an integer: the game accepts nothing else; raise it together with `VERSION`.

## Before release

1. `.venv\Scripts\python.exe tools\validate.py` — 0 errors.
2. `.venv\Scripts\python.exe tools\install.py`, a new game, a pass over [`TESTING.md`](TESTING.md); no errors in the logs.
3. If images changed: `slice_art.py`, `make_art.py`, `make_leader3d.py` (with the 3D leader on), rebuild BLPs (`tools\build.py`), then `make_preview.py`.
4. Update `VERSION` and `version` in `.modinfo`, update `CHANGELOG.md` and `CHANGELOG.ru.md`, commit.

## GitHub Releases

```powershell
.\.venv\Scripts\python.exe tools\package.py
```

`dist/release/` gets `RemselysAlexanderII-v<version>.zip` (inside is the `RemselysAlexanderII` folder to unpack into `Mods`) and `.sha256`. Prepare a single release-notes file with the complete English description first and the corresponding Russian description below. Use that file for the release; keep both changelogs up to date separately. Then:

```powershell
git tag v<version>
git push origin v1.5.0 v<version>   # release branch + tag
gh release create v<version> dist/release/* --title "v<version>" --notes-file <release-notes-file>
```

Repository: `https://github.com/Remsely/civ6-russia-alexander-ii` (the old address `civ6-alexander-ii` redirects).

The archive includes only the files listed in `<Files>` of `.modinfo`: `art/`, `tools/`, `reference/` and the documents are not included.

## Steam Workshop

The page text is in `workshop/description.bbcode`, the preview in `workshop/preview.png` (512x512, generated by `tools/make_preview.py`), settings in `workshop/workshop.json` (`visibility` 2 = hidden until checked). Upload via ModBuddy or steamcmd from an account that owns Civilization VI; after the first publication write `PublishFileID` into `workshop.json`. The mod ships BLPs for Windows and macOS (`tools\build.py` builds both sets); on macOS the mod has not been tested in game.
